# 카운터 태블릿(안드로이드) 키오스크 설정

식당 카운터의 안드로이드 태블릿에 `/counter` 화면 하나만 띄워 두고, USB QR 스캐너(Newland NLS-FR2780 등)로 손님 식권 QR을 찍는 구성입니다.
별도 앱 없이 크롬에 "앱으로 설치"한 뒤 화면 고정으로 잠급니다.

## 준비물

- 안드로이드 태블릿 (안드로이드 10 이상, 크롬 최신)
- USB QR 스캐너 + USB-C OTG 젠더(또는 OTG 허브)
- 충전기: 하루 종일 켜 두므로 **충전하면서 스캐너도 꽂을 수 있는 OTG 허브**(충전 포트 있는 것)를 권장
- 매장 와이파이
- 식당관리자 계정(이메일·비밀번호)

## 1. 앱으로 설치 (주소창 없는 전체화면)

1. 태블릿 크롬에서 `https://greeneatgo.vercel.app/counter` 를 엽니다.
2. 오른쪽 위 ⋮ → **앱 설치** (또는 **홈 화면에 추가** → 설치).
3. 홈 화면에 생긴 **식권 카운터** 아이콘으로 엽니다. 주소창·탭 없이 전체화면(가로)으로 열립니다.
4. 식당관리자 계정으로 로그인합니다. 로그인은 유지되므로 매일 다시 할 필요가 없습니다.

## 2. 화면 고정 (다른 앱으로 못 나가게)

1. 설정 → 보안(또는 생체 인식 및 보안) → 기타 보안 설정 → **앱 고정**(화면 고정) 켜기.
   - "고정 해제 전 PIN 요청"도 켭니다. 직원이 실수로 나가지 않게 합니다.
2. 최근 앱 버튼 → **식권 카운터** 위쪽 아이콘 → **이 앱 고정**.
3. 해제: 뒤로 + 최근 앱 버튼을 동시에 길게 → PIN 입력.

삼성 태블릿은 메뉴 이름이 "앱 고정", 그 외 기종은 "화면 고정"인 경우가 많습니다.

## 3. 꺼지지 않게

- 카운터 화면은 열려 있는 동안 **화면 꺼짐 방지**를 스스로 켭니다(오른쪽 위에 "화면 꺼짐 주의"가 보이면 해제된 상태 → 화면을 한 번 터치).
- 그래도 기기 설정에서:
  - 디스플레이 → 화면 자동 꺼짐: 가장 길게
  - 배터리 → 크롬(그리고 설치된 식권 카운터)을 **절전 예외 / 제한 없음**으로
  - 소프트웨어 업데이트 자동 재시작은 영업시간 밖으로
- 충전기를 계속 꽂아 둡니다.

## 4. 스캐너 연결

- OTG로 꽂으면 키보드로 인식되어 바로 동작합니다(별도 설정 없음).
- 화면 키보드가 뜨지 않도록 카운터 입력칸은 키보드를 띄우지 않게 되어 있습니다.
- 스캐너를 꽂았을 때 "물리 키보드" 알림이 뜨면 무시해도 됩니다.

## 5. 소리

- 사용 완료 시 효과음이 납니다. 브라우저가 소리를 막으면 화면 위에
  **"효과음이 꺼져 있어요. 눌러서 소리 켜기"** 가 뜹니다 → 한 번 누르면 됩니다.
- 태블릿 미디어 볼륨을 충분히 올려 둡니다.

## 6. 화면에서 보이는 상태

| 표시 | 뜻 | 할 일 |
|---|---|---|
| 오른쪽 위 ● 연결됨 | 정상 | 없음 |
| ● 연결 끊김 + 빨간 띠 | 와이파이 끊김 | 와이파이 확인. 연결되면 자동 복구 |
| 화면 꺼짐 주의 | 화면 꺼짐 방지 해제 | 화면 한 번 터치 |
| 효과음이 꺼져 있어요 | 소리 차단 | 띠를 한 번 누르기 |

## 7. 로그아웃

- 실수 방지를 위해 **로그아웃 버튼을 1.5초 길게 눌러야** 로그아웃됩니다(누르는 동안 버튼이 빨갛게 차오름).

## 참고

- 매장이 여러 곳이고 원격 관리(재시작, 화면 확인)가 필요하면 Fully Kiosk Browser 같은 키오스크 전용 앱(유료)으로 바꿀 수 있습니다. 시작 URL만 `https://greeneatgo.vercel.app/counter` 로 두면 됩니다.
- 손님 QR·스캔 규칙은 `docs/COUNTER_SCANNER.md` 참고.
