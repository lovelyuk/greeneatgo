## 1. 디자인 규칙 (반드시 지킬 것)

### 색
| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| 바탕 | `#0A0D14` | 전체 배경, 사이드바 |
| 패널 | `#131A2A` | 카드·표·폼 상자 |
| 강조 패널 | `#1B2436` | 보조 버튼, 막대 그래프 바탕 |
| 선 | `#212B3E` | 입력칸 테두리, 표 머리 밑줄 |
| 절취선 | `#232D44` (2px dashed) | 표 행 사이, 카드 안 구분선 |
| 글자 | `#E9EDF5` / 보조 `#8A93A6` / 흐림 `#6B7489` | |
| 블루 | `#2C5FFF` / 밝은 블루 `#5B87FF` | 주 버튼, 대표 숫자 카드, 오늘 막대 |
| 종이(크림) | `#F4F1E9` | 선택된 메뉴·탭, 티켓 모양 카드 |
| 빨강 | `#FF6B6B` | 환불·삭제·미입금 |
| 노랑 | `#F5B54A` | 대기 상태, 별점 |

- **초록 금지.** 지금 관리자의 초록(#2EA86A 등)은 전부 위 색으로 바꾼다.
- 앱과 같은 팔레트다(`apps/customer/lib/theme/app_colors.dart`).

### 글꼴·숫자
- Pretendard (이미 `public/fonts/`에 있음). 숫자는 `font-variant-numeric: tabular-nums`.
- 금액 표기: `9,961,000원` (₩ 기호 쓰지 않음).

### 핵심 부품
1. **숫자 티켓 카드 (KPI)**: 패널색 카드 오른쪽에 점선 절취선 + 위아래 반원 홈.
   - 왼쪽: 라벨(작게) + 큰 숫자 + 단위. 오른쪽(약 96px): 증감/보조 숫자.
   - 화면마다 3~4장, **가장 중요한 1장만 블루**.
2. **사이드바 (아이콘 + 글자 필수)**: 폭 236px, 그룹 제목 3개
   - 운영: 대시보드, 실시간 매출 / 업체·정산: 업체 정보, 매출 정산, 증빙 내역 / 식당: 식당 관리, 공급자 정보
   - 선택된 메뉴 = 크림색 배경 + 오른쪽 반원 홈(식권 모양). 식당 관리에 새 결제 수 배지.
   - 아래: 식당명·계정 카드, 새로고침, 로그아웃, 개인정보 처리방침·이용약관.
   - **아이콘만 있는 좁은 사이드바는 쓰지 않는다** (사용자 지시).
3. **하위 탭**: 알약 모양, 선택된 탭 = 크림색. (업체 정보 3개, 식당 관리 9개 탭)
4. **표**: 머리글 작게·흐리게, 행 사이 2px 점선, 금액은 오른쪽 정렬·굵게.
5. **상태 표시(pill)**: 둥근 작은 칸 + 점. 정상/완료=블루 계열, 대기=노랑, 환불·미입금=빨강, 해당 없음=회색.
6. **입력칸**: 높이 44px, 진한 바탕 `#0F1420`, 포커스 시 블루 테두리+번짐. 읽기 전용은 점선 테두리.
7. **버튼**: 주 버튼 블루, 보조는 테두리만, 위험(삭제·초기화)은 빨간 글자+빨간 테두리.
8. **종이 티켓(크림색)**: 판매 상품·쿠폰·결제 QR·메뉴 일정처럼 "식권 자체"를 보여줄 때만 사용.
9. **그래프**: 일별 막대 그래프. 휴무일은 0 대신 "휴무" 글자, **오늘 막대만 블루**.

## 2. 적용 순서 (권장)

1. **공통 틀** — 색 변수, 사이드바, 상단바, KPI 카드, 탭, 표, 입력칸, 버튼, pill.
   이것만 바꿔도 전 화면이 새 톤이 됨.
2. **대시보드 → 실시간 매출 → 매출 정산 → 증빙 내역** (매일 보는 화면 먼저)
3. **식당 관리 9개 탭 → 업체 정보 3개 탭 → 공급자 정보**
4. **로그인 화면**
5. **회사관리자 화면** (시안 없음 → 먼저 시안 확인 후 적용)

각 단계마다: 단위 테스트(`npm test`) + 빌드 + 브라우저 테스트 통과 후 커밋 → Preview에서 확인 → "메인에 병합해줘" 때 운영 반영.

## 4. 바꾸면 안 되는 것 (기능 보호)

- **디자인만 바꾼다.** API 호출, 계산, 권한, 저장 동작은 그대로.
- 브라우저 테스트가 찾는 **문구·역할은 유지**: 로그인 버튼 "운영 시작하기", 메뉴 이름(대시보드·실시간 매출 등), 탭 이름, 각 화면 제목. 바꿔야 하면 `apps/admin/browser/` 테스트도 같은 커밋에서 수정.
- `/shop`(구매자 웹)과 `/counter`(카운터)는 **이번 대상 아님** — 이미 다크 디자인.
- 회사관리자·플랫폼관리자 화면도 같은 `style.css`를 쓰므로, 공통 틀 변경 후 그 화면들이 깨지지 않았는지 캡처로 확인.
- 개인정보 처리방침·이용약관 링크는 사이드바 아래에 계속 보이게.
